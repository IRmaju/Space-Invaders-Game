# 🛸 **Space Invaders  Game** 🚀

Welcome to the **Space Invaders** game built using **Streamlit**! This is a simple, yet fun, space-themed game where you control a spaceship to defeat alien invaders.

---

## 🎮 **Game Overview**

In this game:
- You control a spaceship using left and right buttons.
- Shoot bullets to defeat the invading aliens.
- Each alien hit increases your score by 10 points.
- Aliens are constantly moving down, and if they collide with your spaceship, you lose a life.
- You have 3 lives in total. If you lose all your lives, the game is over!

---

## 🚀 **Game Controls**

- **⬅️ Move Left**: Move your spaceship to the left.
- **➡️ Move Right**: Move your spaceship to the right.
- **🔫 Shoot**: Shoot bullets to destroy aliens.
